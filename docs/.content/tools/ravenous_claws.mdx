# Ravenous Claws

This weapon is a living tool which runs on nutrients instead of durability.

It features an Awakened mode where it gains 2.5 extra damage and abilities when activated.
In awakened mode the blood charge is consumed instead of nutrients.

<PrefabObtaining />

## Operation

- kill mobs while holding this weapon in the main-hand to gain blood charge
- when you have any blood charge you can press the action key to toggle between default and awakened mode

## Abilities

### Eviscerating Slash

When triggered, adds one level of Bleed effect up to a max stack of 2.

### Blood Explosion

Requires Awakened Mode

On Bleed Stack, deals 10% of max health as damage.

## Repair

This is a living tool that consumes uses raw meat or nutrients to repair itself.
You have to feed the tool with these items while inside the inventory GUI as you would fill a bundle.
