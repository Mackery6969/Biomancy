# Chrysalis

Allows you to capture and indefinitely store any mob that is not a boss (i.e. [](@c:bosses)) or
invalid for capture (i.e. [](@c:capturing_not_supported)). 

<Callout variant="warning">
Creative mode ignores the capture limitations which allows you to capture mobs like the ender dragon.
</Callout>

<PrefabObtaining />

## Usage
- Right click with a empty chrysalis on a supported mob
- Shift click on the ground to release the stored mob
