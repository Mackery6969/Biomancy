# Modular Larynx

- Plays Mob Sounds with controllable pitch like a noteblock

<PrefabObtaining />

## Usage

- insert [mob essence](@biomancy:essence) with `Right Click` to set which mob sounds to use
- `Shift Right-Click` with empty hand to the extract mob essence
- mob essence can be inserted and extracted with hoppers
- plays sound on redstone signal
- plays sound on player hit

### Mob Sound Types

The sound type played depends on the block placed directly underneath the modular larynx.

| Block                                              | Mob Sound Type    |
|----------------------------------------------------|-------------------|
| [](@minecraft:soul_sand), [](@minecraft:soul_soil) | mob death sound   |
| [](@minecraft:magma)                               | mob hurt sound    |
| Other                                              | mob ambient sound |
