# Decomposer

Decomposes items into base components.

- Machine block used to decompose items into components used for crafting
- Only way to get components
- Nutrient Fuel Storage: 1000 units

## Operation

- Requires fuel, each craft uses up 1 fuel
- Fuel input slot receives (Food, Nutrients, Nutrient Paste, Nutrient Bar)
- Input slot receives items
- Output depends on item input and varies
- The item has X time to be decomposed, represented in the progress bar above the input slot.
- The machine holds the results after you exit it and can work autonomously
