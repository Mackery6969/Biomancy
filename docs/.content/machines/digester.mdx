# Digester

Converts food and plant material into [](@biomancy:nutrient_paste).

- Receives "food" on the input slot and outputs [](@biomancy:nutrient_paste)
- Raw or cooked has no difference
- Does not use fuel, instead the machine gets its own fuel from the items it eats
- Different foods vary in output amounts

## Operation

- Each craft costs a fixed amount of fuel
- Fuel input slot receives (Food, Nutrients, [](@biomancy:nutrient_paste), [](@biomancy:nutrient_bar))
