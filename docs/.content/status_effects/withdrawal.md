# Withdrawal

- occasionally applies [Nausea](https://minecraft.wiki/w/Nausea) for a short while
- applies attribute modifiers similar to [Slowness II](@minecraft:slowness) + [Weakness I](@minecraft:weakness) + [Mining Fatigue I](@minecraft:mining_fatigue)
- not curable with milk
- eating sugary foods reduces duration
