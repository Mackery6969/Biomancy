# Armor Shred
Armor Shred is a negative status effect that reduces the afflicted mob/player’s armor points, 
and it can be stacked when acid corrodes a mob/player for an extended period of time.

- status effect stacking -> level increases by 1 when the effect is applied again
- reduces total armor by 5% per level up to 100% reduction
