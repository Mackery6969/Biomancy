# Primordial Infestation

- Affected Players will talk in Caro Invitica in the chat (you can hover on the message to read the original message).
- Renaming items in the anvil will give them the Caro Invitica font. Also works with name tags which allows you to name mobs with the font. (name tags from other mods should work as well)
- Editing signs will also give them the Caro Invitica font
- On death (player or mob) will spread malignant veins & blocks
