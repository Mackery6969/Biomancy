# Despoil

This enchantment allows [biomancy specific items to drop]($loot/despoil_loot) when killing mobs that would drop them
when killed with the [](@biomancy:despoil_sickle).
A higher level Despoil level will yield more drops and higher drop chances.

## Applicable to:
- Swords
- Claws
- Axes
- Knives
