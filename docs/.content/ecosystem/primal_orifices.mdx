# Primal Orifice

## Obtaining
Naturally grow inside [flesh mound]($getting_started/mound) chambers below the cradle or 
other chambers depending on the seed of the flesh mound.

Primordial Orifices can be broken and placed elsewhere.

## Usage
These blocks produce [gastric acid]($getting_started/gastric_acid) overtime, and if left unattended for too long, 
will spawn acid projectiles underneath them which will place gastric acid fluid blocks on impact.

You can collect [](@biomancy:acid_extract) with vials from orifices that leak acid. 
Buckets can be used on full orifices to collect gastric acid fluid.
