# Insomnia Cure

Experience sleep-free tranquility with this remarkable serum. Temporarily eliminating the need for rest,
it provides boundless wakefulness while keeping the haunting phantom at bay.

Explore, create, and conquer the realm unhindered by sleep or the relentless phantom menace.

## Effect on Players

- resets last slept timer (insomnia)
- phantoms that target the affected player receive magic damage
- applies temporary [Blindness](@minecraft:blindness) and [Darkness](@minecraft:darkness) status effects

## Effect on Mobs

Not applicable.
