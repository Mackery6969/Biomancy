# Flesh Pig
- attacks players, [](@minecraft:villager) and all non-pig type animals
- alerts others when attacked
- seeks out raw meat items which it eats to heal itself, grow up faster or to enter breeding mode
- when it eats pork it gains the [](@biomancy:frenzy) effect for 60 seconds

## Obtaining
- occasional side effect of using [](@biomancy:breeding_stimulant) on pigs
